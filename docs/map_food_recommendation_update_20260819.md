# 전라남도 고정 지도 + AI 음식 추천 지도 연동 (2026-08-19)

## 동작
- 첫 화면 지도: 광주 3개 거리를 제외하고 전라남도 음식특화거리 33개만 표시
- 지도 탐색 범위: 전라남도 권역을 중심으로 maxBounds 적용, 권역 밖으로 과도하게 이동하지 않도록 제한
- AI 추천: foods.json 296개 음식의 맵기/국물/날것/주재료/제철월을 사용
- 추천 후 지도: 추천 음식별로 좌표가 있는 전남 식당을 최대 2곳씩 음식 아이콘 핀으로 추가
- 추천 직후: 첫 추천 음식의 첫 전남 식당 위치로 flyTo
- 추천 카드: `지도에서 이 음식 보기` 버튼으로 해당 음식 위치로 이동

## 데이터 커버리지
- 전남 좌표 보유 음식특화거리: 33개
- 제외되는 광주 음식특화거리: 3개
- 전체 음식: 296개
- 전남 식당 좌표가 최소 1개 있는 음식: 272개
- 전남 식당 좌표가 없는 음식은 좌표를 임의 생성하지 않으며 지도 핀을 만들지 않음
