# 남도 입맛 — 취향으로 찾는 제철 음식과 특화거리

맵기·짠맛·국물·식감·향신료 다섯 축을 1~5로 받아, **지금 제철인 광주·전남 음식**을
추천하고 그 음식이 **실제로 모여 있는 지역특화거리**로 연결하는 웹서비스.

## 왜 이렇게 만들었나

원본 공공데이터에는 맛에 대한 정보가 한 글자도 없다. 제철 식재료 목록, 식당·메뉴
목록, 특화거리 목록이 각각 따로 있을 뿐이다. 그래서 세 가지를 직접 만들었다.

1. **맛 프로파일** — 메뉴명에서 5축 점수를 산출하는 룰 엔진 (`../src/taste/rules.py`).
   조리법이 국물·짠맛을 지배하고 주재료가 식감·향을 지배한다는 전제로 사전을 짰다.
   근거가 약한 행(신뢰도 < 0.6)만 Claude로 재평가한다.
2. **거리 큐레이션** — 특화거리 32건에 업종과 대표 식재료를 손으로 붙였다
   (`../src/streets/build_streets.py`). 32건뿐이라 자동 태깅보다 정확하고 검증도 쉽다.
3. **매칭 규칙** — 취향 벡터 거리 + 제철 필터로 음식을 고르고, 식재료 키워드 →
   행정구역 → 좌표 근접 순으로 거리를 붙인다 (`lib/recommend.ts`).

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm run start
```

데이터는 빌드 시점에 번들로 굳는다. 서버도 DB도 API 키도 필요 없다.

### 데이터 갱신

`public/data/*.json`은 파이썬 파이프라인의 산출물이다. 원본 CSV를 고쳤다면
저장소 루트에서 다시 만든다.

```bash
python -m src.taste.build_taste_profile   # 메뉴별 5축 맛 점수
python -m src.taste.llm_refine            # (선택) 저신뢰 행만 LLM 재평가
python -m src.streets.build_streets       # 특화거리 정제
python -m src.export.build_web_data       # → web/public/data/*.json
```

`llm_refine`은 `ANTHROPIC_API_KEY`가 있을 때만 동작한다. 없으면 건너뛰고
룰 엔진 결과만으로 끝까지 돌아간다.

## 구조

```
app/
  page.tsx              취향 입력 (5축 슬라이더)
  TasteForm.tsx         └ 슬라이더 상태와 제출 (client)
  result/page.tsx       추천 결과 — 음식 카드 + 거리 랭킹 + 지도
  street/[id]/page.tsx  거리 상세 — 지도, 지표, 연결된 음식, 파는 곳
components/
  TasteSlider.tsx       축 색을 그대로 쓰는 1~5 슬라이더
  TasteChart.tsx        5축 미니 막대 + 사용자 취향 목표선
  RegionMap.tsx         좌표 직접 투영 SVG 산점도 (지도 API 불필요)
lib/
  recommend.ts          매칭 엔진 — 유사도, 다양성, 거리 매칭, URL 직렬화
  korean.ts             조사 처리, 거리 표시명 보정
  types.ts              데이터 타입 + 축 메타(라벨·색)
  data.ts               JSON 번들 로더
```

## 매칭 엔진에서 눈여겨볼 것

**축 가중치.** 3(무관심)에서 멀리 민 축일수록 가중치가 올라간다. "국물 5"라고
말한 사람에게 국물 없는 음식이 올라오지 않게 하려는 것이다.

**신뢰도 감점.** 맛 점수의 근거가 약한 음식은 최종 점수를 조금 깎는다
(`0.85 + 0.15 × confidence`). 추측이 근거를 이기고 1위에 오르면 사용자가
이유를 납득할 수 없다.

**재료 다양성.** 점수순 정렬만 하면 "전복문어탕·전복연포탕·전복해신탕·전복삼계탕"처럼
한 재료가 목록을 독점한다. 재료당 2개까지만 먼저 채우고 나머지는 뒤로 미룬다.

**거리 매칭은 키워드 우선.** 낙지를 추천받은 사람에게 무안뻘낙지거리를 보여 주는
편이, 단지 가깝다는 이유로 다른 거리를 보여 주는 것보다 쓸모 있다. 좌표 근접은
보조 신호로만 쓴다.

## 알려진 한계

- **맛 점수는 메뉴명 추정치다.** 실제로 먹어 보고 매긴 점수가 아니다. 근거가 약한
  항목은 화면에 "※ 메뉴명 정보가 짧아 맛 점수의 근거가 약합니다"로 표시된다.
- **지도는 좌표 산점도다.** 도로·건물이 없다. 실제 길찾기는 카카오맵 링크로 넘긴다.
- **특화거리 32건 중 음식 카테고리는 20건**이고, 그중 대표 식재료가 붙은 것은 16건이다.
  나머지는 지역·좌표로만 매칭된다.
- **좌표 결측 2건**(함평천지 한우비빔밥, 목포 사후면세점)은 주소 기준으로 보정했고,
  화면에 그 사실을 밝힌다.
